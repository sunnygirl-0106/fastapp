二、按任务章节说明
第 1 节：完成过期文档清理，并修复保留文档中的失效引用。代码没有引用被删除文档。

第 2 节：段落原文只要真正改变，就写入 segText 待更新原因；没有 silent 分支。
删除第 2 步忽略、已忽略/撤销、错别字复选框。保存提示仍为“已保存，镜头 NN 需要更新”。
生成过程中改原文的原因积压、重复原因去重逻辑保留。标题修改不新增原因。

第 3 节：琥珀色待更新标签保留原样；忽略移到右侧，使用 text-white/35、hover:text-white/70，
没有底色、边框或分隔线；全部忽略使用同样的灰色。保留忽略时取消选择和后续新修改重新选中的行为。

第 4 节：每拍一个独立 contenteditable，序号在编辑区外显示，不能选中或编辑。
使用 flex 固定序号栏，使长内容换行对齐该拍文字首字；拍间有间距。
支持光标处回车拆拍、行首退格并拍、空拍删除、第一拍行首保护、添加一拍；粘贴多行逐行去序号。
支持 ①…⑳ 和 21. 等后续编号。空拍在编辑期间保留，保存时由 timelineLines/formatTimeline 去掉。
表格查看态也采用独立序号和悬挂缩进。视频提示词与已有镜头编码继续使用同一存储格式。

第 5 节：十个镜头文字字段在表格和抽屉内均使用 ShotTextEditor；第 2、3 步没有加入此组件。
@ / ＠ 唤起项目所有角色和场景，已引用资产优先，其余角色优先于场景；支持名称和别名过滤。
候选提供图片/占位、正式名称、资产种类及无匹配提示；支持上下、回车、Tab、Esc 和鼠标确认。
光标移动、失焦或输入空格关闭列表；选择后写半角 @名称，不添加空格，光标位于名称之后。
已知名称成为不可进入的整体标签，角色/场景双色，支持悬停参考图；退格一次删除整枚标签。
手工输入完整名称同样识别；未知名称保留可编辑文字、红色虚线及原有提示。
底层仍是纯文本，沿用改名同步和视频提示词替换。
compositionstart 到 compositionend 期间不重建 DOM、不弹候选、不提交组字内容；
Enter/Esc/keyCode 229 不触发编辑器和抽屉快捷键，组字结束后再恢复匹配与保存。

第 6 节：
- 保存任何镜头文字字段时，先合并完整镜头，再按“画面描述 → 画面节奏 → 主要动作 → 场景位置 →
  动作说明 → 走位说明 → 画面主角 → 连贯要求 → 保持不变 → 背景范围”推导 assetIds，首次出现去重。
- 新增引用带上参考图，所有引用移除后去掉对应 ID；已有视频才按 B 类标记待更新。
- 模型输出仍严格要求其他字段的引用已出现在画面描述中，并按画面描述修正 asset_ids。
- LENGTH_RANGES、BANNED_WORDS、visibleLength、styleNotes 与 Python 对齐，包括 Unicode 字符计数、
  引号对白排除、无位移下限豁免，以及影像/画像等“像”的例外。
- validateShots 添加 notes；编辑时也实时显示各字段建议。建议不会抛错，不引发重试或增加模型调用。
- Python 对照包含常规镜头、短字段/禁词、别名之外的正式名称引用、最长名称、重复引用、
  引号、无位移、多句号、补充平面字符等样例。

第 7 节：继续使用现有 1 秒轮询监听，文档更新时失效模块缓存、发送 full-reload，并输出
“提示词文档已更新，已重新读取并刷新页面”。

验证使用临时副本，覆盖普通写入和 rename 整文件替换，未为测试修改正式提示词文档。
