# 工作流优化需求

## 一、前三步做完就不能再改
> 已调整：2026-11 起仅「剧本」锁定，拆解与角色场景改为待更新机制，见 docs/Codex任务-任意时长与取消锁定.md

剧本、拆解、角色与场景这三步，一旦下一步开始生成，就固定下来不能再改了。因为后面的内容都是基于它们生成的，改了会前后对不上，而且用户已经花过星钻。

- 锁定时机：开始拆解 → 剧本锁定；开始提取角色场景 → 拆解锁定；开始生成镜头 → 角色与场景锁定。
- 镜头和成片这两步不锁，随时可以改、可以重新生成。
- 锁定只是不能改，不影响回去查看。

体验上：

- 已锁定的步骤，标题旁边给个「仅供查看」的标识。
- 所有能编辑的地方都置灰：输入框、新增、删除、重做、重新生成、行内编辑等等。
- 鼠标移上去给 tooltip 说明原因，别让用户对着灰按钮猜：
  - 步骤条上还没走到的步骤：「完成上一步后解锁」
  - 步骤条上已锁定的步骤：「该步骤已用于后续生成，仅供查看」
  - 置灰的按钮和输入框：「后续步骤已开始生成，此处不可修改」
- tooltip 稍微延迟一点再出现，跟着鼠标位置浮在上方，别被卡片或弹窗裁掉。

## 二、生成视频可以选模型

生成视频的确认弹窗里，模型要能选，默认 Seedance 2.0。

- 分辨率和画面比例也做成可选的（现在是写死的展示），但**可选项由模型决定**——换一个模型，参数选项跟着换。
- 如果换模型后当前参数它不支持，自动退回该模型的默认值，并顺带提示一句。
- 画面比例默认跟项目设置走（现在是 9:16）。
- 模型和分辨率不同，价格也不同，弹窗里的预计消耗和生成后余额要跟着变；余额不够就不让点确认，提示去充值。
- 同一个项目记住上次选的模型和参数，下次默认带出来。
- 批量生成和单个镜头重新生成，用同一套选择面板。

## 三、多次生成的视频怎么展示

同一个镜头每生成一次就多一个版本，旧的永远保留（是用户花钱买的）。

- 第一次生成就显示 v1（之前 v1 是藏起来的）。
- 每个镜头卡片下面把它的版本都列出来：v1 v2 v3，当前用的那个高亮，点一下就切换预览和封面。
- 预览弹窗里也常驻版本切换，只有一个版本时就显示成一个 v1 标签。
- 当前选中的版本决定：镜头封面、项目封面、批量下载下下来的是哪一版。
- 每个版本记一下生成时间、用的模型和分辨率、花了多少星钻，鼠标移上去能看到，方便判断留哪一版。
- 批量下载的文件名带上版本号，比如「镜头01_v2.mp4」。

## 补充几条

- 生成失败不扣费、也不占版本号，避免出现一个空的 v2。
- 分镜改过之后，旧视频标记「需重新生成」；重新生成出来的新版本自动设为当前采用的版本。
- 锁定状态下，「重新拆解」「重新提取」这类按钮同样置灰。
